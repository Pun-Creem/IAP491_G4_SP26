=== NHOM 1: PIPELINE DAY DU (giong phien ban goc) ===

--------------------------------------------------------------------------------
2.1 auto_sim2action.py - Pipeline chinh (1 mau)
--------------------------------------------------------------------------------
  Mo ta: Xu ly 1 bao cao JSON qua 7 giai doan.

  7 Giai doan:
    1. Trich xuat pattern (Signature, TTP, MBC)
    2. Cap nhat qua VirusTotal (tuy chon)
    3. Tinh do tuong dong (Jaccard/Cosine)
    4. Gop diem tuong dong (trong so)
    5. Chon Top-K mau tuong dong nhat
    6. Anh xa TTP -> D3FEND actions
    7. Tinh diem: score(a) = W * px(a) + beta * sum(sim_j * yj(a))

  Lenh chay:
    python auto_sim2action.py --sample report.json
    python auto_sim2action.py --sample report.json --metric cosine --W 0.3 --beta 0.7
    python auto_sim2action.py   (mo GUI)

  Tham so:
    --sample          : File JSON (bat buoc)
    --out-dir         : Thu muc dau ra
    --metric          : jaccard | cosine
    --w-sig/--w-mbc/--w-ttp : Trong so 3 loai pattern (tong = 1.0)
    --top-k           : So mau tuong dong (mac dinh: 5)
    --W               : Trong so mau chinh
    --beta            : Trong so lang gieng
    --vt-key          : API key VirusTotal
    --no-vt           : Bo qua VirusTotal
    --tfidf-pattern   : Dung TF-IDF

  Dau vao: File JSON + data/
  Dau ra:  output/<ten_mau>/<mau>_action_scores.csv (va cac file trung gian)

=== NHOM 2: SU DUNG TOP-K DA TINH SAN (MOI - CHI CO TRONG ASA MODIFIED) ===

--------------------------------------------------------------------------------
2.4 action_from_topk.py - Tinh action scores tu Top-K co san
--------------------------------------------------------------------------------
  Mo ta: Tinh diem action ma KHONG can chay lai pipeline 7 buoc.
         Su dung file Top-K similarity da duoc tinh san truoc.

  Lenh chay:
    python action_from_topk.py --sample-dir sample/ --topk-dir "sample top k similarity/report_XGBoost"
    python action_from_topk.py   (mo GUI chon thu muc)

  Tham so:
    --sample-dir      : Thu muc chua file JSON
    --topk-dir        : Thu muc chua file Top-K similarity (CSV/XLSX, dat ten theo sha256)
    --W               : Trong so mau chinh (lay tu config_eval.json neu khong chi dinh)
    --beta            : Trong so lang gieng
    --out-dir         : Thu muc dau ra

  Dau vao:
    - File JSON bao cao malware (trong sample-dir)
    - File Top-K similarity da tinh san (trong topk-dir)
      Moi file dat ten theo sha256 cua mau, vd: abcd1234....csv
      Noi dung: danh sach cac mau tuong dong va diem tuong dong
    - config_eval.json (W, beta, duong dan data)

  Quy trinh:
    1. Doc sha256 va TTPs tu JSON
    2. Tim file Top-K tuong ung (theo sha256)
    3. Doc danh sach lang gieng va diem tuong dong
    4. Anh xa TTPs -> D3FEND actions (px)
    5. Tinh: score(a) = W * px(a) + beta * sum(sim_j * yj(a))

  Dau ra:
    - output/<mau>_action_scores.csv

--------------------------------------------------------------------------------

  Tham so:

  Dau ra:

  Mo ta: Thu nghiem nhieu bo trong so W/beta bang cach:

         Phase 2: Moi config chi tinh lai action scores + P/R/F1

  Lenh chay:
    python run_multi_config_eval.py --sample-dir sample/ --topk-dir sim_folder/

  Dau vao:

  Dau ra:
