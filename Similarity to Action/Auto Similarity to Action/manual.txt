--------------------------------------------------------------------------------
2.1 auto_sim2action.py - Pipeline chinh (1 mau)
--------------------------------------------------------------------------------
  Mo ta: Xu ly 1 bao cao JSON qua 7 giai doan de tao danh sach
         hanh dong phong thu D3FEND duoc xep hang.

  7 Giai doan:
    1. Trich xuat pattern (Signature, TTP, MBC) tu JSON
    2. Cap nhat TTP/MBC qua VirusTotal API (tuy chon)
    3. Tinh do tuong dong (Jaccard hoac Cosine)
    4. Gop 3 diem tuong dong thanh 1 (trong so)
    5. Chon Top-K mau tuong dong nhat
    6. Anh xa TTP -> D3FEND actions
    7. Tinh diem action: score(a) = W * px(a) + beta * sum(sim_j * yj(a))

  Lenh chay:
    python auto_sim2action.py --sample report.json
    python auto_sim2action.py --sample report.json --metric cosine --W 0.3 --beta 0.7
    python auto_sim2action.py   (mo GUI chon file)

  Tham so:
    --sample          : Duong dan file JSON (bat buoc)
    --out-dir         : Thu muc dau ra (mac dinh: output/<ten_mau>)
    --metric          : jaccard | cosine (mac dinh: jaccard)
    --w-sig           : Trong so Signature (mac dinh: 0.33)
    --w-mbc           : Trong so MBC (mac dinh: 0.33)
    --w-ttp           : Trong so TTP (mac dinh: 0.34)
                        (w-sig + w-mbc + w-ttp phai bang 1.0)
    --top-k           : So luong mau tuong dong (mac dinh: 5)
    --W               : Trong so cua mau chinh (mac dinh: 1.0)
    --beta            : Trong so cua cac mau lang gieng (mac dinh: 1.0)
    --vt-key          : API key VirusTotal
    --no-vt           : Bo qua lam giau VirusTotal
    --tfidf-pattern   : Ap dung TF-IDF truoc khi tinh tuong dong
    --keep-process-data : Giu lai file trung gian (mac dinh: true)

  Dau vao (Input):
    - File JSON bao cao malware (vd: 1017_report.json)
    - Cac file data trong thu muc data/

  Dau ra (Output) - luu trong output/<ten_mau>/:
    - <mau>_signatture.csv          : Pattern Signature
    - <mau>_ttp_update.csv          : Pattern TTP
    - <mau>_mbc_update.csv          : Pattern MBC
    - <mau>_signature_similarity.csv: Diem tuong dong Signature
    - <mau>_ttp_similarity.csv      : Diem tuong dong TTP
    - <mau>_mbc_similarity.csv      : Diem tuong dong MBC
    - <mau>_merged_similarity.csv   : Diem tuong dong tong hop
    - <mau>_top5.csv                : Top-K mau tuong dong nhat
    - <mau>_mapped_action.csv       : Anh xa TTP -> Actions
    - <mau>_action_scores.csv       : ** KET QUA CHINH ** (danh sach actions xep hang)

--------------------------------------------------------------------------------
2.2 auto_sim2action_multi.py - Chay nhieu mau (batch)
--------------------------------------------------------------------------------
  Mo ta: Wrapper chay pipeline cho nhieu file JSON cung luc.

  Lenh chay:
    python auto_sim2action_multi.py --sample-dir sample/
    python auto_sim2action_multi.py --samples s1.json s2.json s3.json
    python auto_sim2action_multi.py   (mo GUI chon file)

  Tham so:
    --sample-dir      : Thu muc chua cac file JSON
    --samples         : Danh sach file JSON
    (Cac tham so khac duoc chuyen tiep cho auto_sim2action.py)

  Dau vao: Nhieu file JSON
  Dau ra:  Moi mau tao 1 thu muc rieng trong output/
           In tom tat: X/Y thanh cong, liet ke mau loi

--------------------------------------------------------------------------------
2.3 auto_precision&recall.py - Danh gia tu dong
--------------------------------------------------------------------------------
  Mo ta: Chay pipeline cho nhieu mau, tinh Precision/Recall/F1,
         roi don dep thu muc output.

  Lenh chay:
    python auto_precision&recall.py --sample-dir sample/

  Dau vao:
    - Cac file JSON bao cao malware
    - precision&recall/sample_ground_truth/sample_ground_truth.xlsx
      (cot: sha256, actions)

  Dau ra:
    - precision&recall/precision_recall_f1_results.csv
      Cot: sha256, precision_top1..5, recall_top1..5, f1_top1..5
      Dong cuoi: AVERAGE (gia tri trung binh)

--------------------------------------------------------------------------------
2.4 run_multi_config.py - Chay nhieu cau hinh trong so
--------------------------------------------------------------------------------
  Mo ta: Toi uu hoa viec thu nghiem nhieu bo trong so (W/beta)
         bang cach cache cac buoc khong phu thuoc trong so.

  Lenh chay:
    python run_multi_config.py --sample-dir sample/

  Quy trinh:
    Phase 1 (1 lan): Chay stage 1-4 & 6 cho tat ca mau, cache lai
    Phase 2 (moi config): Chi chay lai stage 5 & 7 voi W/beta khac nhau

  Dau vao:
    - Cac file JSON bao cao malware
    - config_list.csv (danh sach cau hinh)
    - config.json (cau hinh co so)

  File config_list.csv:
    run,metric,w_sig,w_mbc,w_ttp,top_k,W,beta,tfidf_pattern
    1,jaccard,1,0,0,5,0,1,FALSE
    2,jaccard,1,0,0,5,0.1,0.9,FALSE
    ...
    11,jaccard,1,0,0,5,1,0,FALSE

  Dau ra:
    - precision&recall/<run_number>.csv cho moi cau hinh
